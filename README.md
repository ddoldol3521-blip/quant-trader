# quant-trader

한국·미국 주식 대상 퀀트 전략 백테스트 + 스캔 도구. **자동 주문 기능은 없습니다** — 신호를 찾아주면 실제 매매는 본인이 증권사 앱에서 직접 합니다.

## 한국 / 미국 전환

앱 맨 위의 **🇰🇷 한국 주식 / 🇺🇸 미국 주식** 선택으로 전체 앱이 전환됩니다. 종목 검색·차트·백테스트·스캔·포트폴리오·텔레그램 예약이 모두 선택한 시장을 따라갑니다 (통화 표시도 원/달러로 바뀜).

| | 한국 | 미국 |
|---|---|---|
| 시장 | KOSPI, KOSDAQ | S&P500, NASDAQ, NYSE |
| 종목 지정 | 종목코드 (005930) | 티커 (AAPL) |
| 통화 | 원 | 달러 |
| 목록 순서 | 시가총액 큰 순 | NASDAQ·NYSE는 시가총액 순, **S&P500은 알파벳순** |

**S&P500 주의**: 알파벳순으로 오기 때문에 "상위 100개"를 고르면 규모 상위가 아니라 A로 시작하는 회사 위주가 됩니다. 앱에서 이 경우 경고를 띄웁니다. 규모 순으로 보려면 NASDAQ·NYSE를 쓰세요.

## 실행 방법

앱이 **두 개**입니다. 바탕화면 바로가기를 더블클릭하면 됩니다.

| 바로가기 | 용도 | 포트 |
|---|---|---|
| **종사종팔 V5** | 매일 쓰는 것. SOXL 분할매매 '오늘 뭘 할지'만 | 8502 |
| **퀀트트레이더 웹** | 분석 도구 모음 (백테스트·스캔·상황판 등 15개 탭) | 8501 |

**매일 매매하실 거면 "종사종팔 V5"만 켜면 됩니다.**

### 종사종팔 앱은 매매 기록을 받지 않습니다

시작일과 규칙(분할수·목표수익률·청산일)이 정해지면 **그날부터 오늘까지의 모든 매매가 자동으로 결정**됩니다. 그래서 이 앱은 매번 시작일부터 다시 계산합니다.

맨 위에서 정하는 것은 7가지뿐입니다: **종목 · 시드 · 분할수 · 시작일 · 목표수익률 · 청산 영업일 · 수수료 · 수익 재투자 여부.** 넣는 즉시 아래 현황(총자산/누적손익/누적수익률/남은현금/현재가/현재보유)과 오늘 넣을 주문이 다시 계산됩니다.

- **수익 재투자 ⭕** — 하루 매수금 = *어제 마감 총자산*의 1/분할수 (복리, 원본 V5 방식)
- **수익 재투자 ❌** — 하루 매수금 = *넣은 돈*의 1/분할수 (고정. 중간 입금분은 반영, 이익만 제외)

### 중간에 돈을 넣거나 뺐다면

설정 아래 **"💰 중간에 돈 넣고 뺀 기록"** 에 날짜·구분(입금/출금)·금액만 적으면 됩니다. 매매 기록은 여전히 필요 없습니다.

입출금이 생기면 `총자산 ÷ 시드 - 1`은 더 이상 수익률이 아니므로(돈을 더 넣어서 는 것과 벌어서 는 것을 구분 못 함) 지표를 나눠서 계산합니다.

| 지표 | 기준 |
|---|---|
| 누적 손익금 · 누적 수익률 | **넣은 돈**(시드 + 입금 − 출금) 대비 |
| CAGR · MDD · 연도별 수익률 | **시간가중수익률(TWR)** — 입출금 효과를 제거한 전략 자체의 성적 |
| 자산 그래프 | 실제 금액 그대로 |

TWR을 쓰지 않으면 입금한 날이 자산 신고점이 되어 낙폭이 실제보다 얕게 나옵니다.

처리 규칙:
- 주말·공휴일 입출금 → 다음 거래일에 반영 (화면에 안내)
- 출금액 > 예수금 → **규칙을 어기고 강제 매도하지 않고**, 가능한 만큼만 빼고 나머지는 예수금이 생길 때까지 이월
- 출금액 > 총자산 → 입력 실수로 보고 전액 출금으로 자름 (화면에 안내)

### 존버 vs 전략

"오늘 할 일" 탭 맨 아래에 **첫날 전액 매수하고 그냥 놔둔 경우(존버)** 와 비교하는 그래프·표가 있습니다. 입출금도 똑같이 반영해 공정하게 비교합니다.

이 전략은 평균적으로 자산의 20~25%만 주식이고 나머지는 현금이라, 상승장에서는 존버가 이기는 게 정상입니다. **수익률이 아니라 낙폭 차이를 보라고 만든 화면입니다** (SOXL 2025~2026 기준 존버 -76% vs 전략 -40%).

### 배당

배당락일에 들고 있던 수량만큼 받습니다. 받은 배당은 **따로 쌓이고 매매에 쓰지 않습니다** — 총자산에는 더해지지만 하루 매수금을 정하는 기준액에서는 빠집니다(재투자 안 함). 존버 비교 쪽도 같은 규칙으로 받습니다.

시세(FinanceDataReader / yfinance `auto_adjust=False`)의 종가는 배당이 반영되지 않은 값이라 따로 더해야 실제 계좌와 맞습니다 — 확인 방법은 `src/data/kr_data.py`의 `get_dividends()` 주석에 있습니다.

SOXL 기준으로는 금액이 작습니다. 2011~2026 15년을 돌리면 주당 합계 $1.106, 실제로 받은 돈은 총자산의 **0.41%**(CAGR +0.03%p)입니다. 배당락일에 현금만 들고 있으면 못 받아서, 30번 중 26번만 받았습니다.

설정값은 `jongsa_settings.json`에 저장되며, 보유 내역이나 매매 기록은 저장하지 않습니다. 규칙을 어긴 매매를 하셨다면 화면 숫자와 실제 잔고가 달라집니다.

## 웹에 올리기

**[DEPLOY.md](DEPLOY.md)** 에 단계별 안내가 있습니다 (Streamlit Community Cloud, 무료, 20~30분).

여러 사람이 접속하는 서버에서는 설정을 파일에 저장하지 않습니다 — 접속자끼리 서로의 설정을 덮어쓰기 때문입니다. 그런 환경에서는 설정이 브라우저 세션 안에서만 유지됩니다. 판별은 `src/jongsa_live.py`의 `is_shared_server()`가 하며, Streamlit Cloud(`/mount/src` 존재) 또는 환경변수 `QUANT_SHARED_SERVER=1`로 켜집니다.

직접 실행하려면:

```powershell
.venv\Scripts\python.exe -m streamlit run jongsa_app.py --server.port 8502
.venv\Scripts\python.exe -m streamlit run app.py
```

두 앱은 서로 상태를 공유하지 않습니다 — 종사종팔 설정은 전용 앱에서만 관리합니다.

## 지원 전략 (9개)

크게 두 종류로 나뉩니다.

**오르는거 따라사기 (추세추종)**
| 이름 | 매수 | 매도 |
|---|---|---|
| `golden_cross` | 단기 이평선이 장기 이평선 위로 돌파 | 반대로 아래로 이탈 |
| `macd` | MACD선이 시그널선 위로 돌파 | 아래로 이탈 |

| `volatility_breakout` | 전일 변동폭의 k배만큼 시가 위로 상승 | 다음날 조건 미충족 시 |

**싸졌을때 줍기 (평균회귀)**
| 이름 | 매수 | 매도 |
|---|---|---|
| `rsi` | RSI 30 밑 (과매도) | RSI 70 위 (과매수) |
| `bollinger` | 볼린저밴드 하단 이탈 | 중심선 회복 |
| `disparity` | 이격도 95 밑 (평균보다 5%↓) | 이격도 102 회복 |
| `stochastic` | %K 20 밑 | %K 80 위 |

**가장 안전**
| 이름 | 매수 | 매도 |
|---|---|---|
| `high_breakout` | 최근 1년 최고가 갱신 | 최고가 아래로 하락 |

새 전략을 추가하려면 `src/strategies/`에 같은 인터페이스(`generate_signals`, `DEFAULT_PARAMS`, `BUY_CONDITION`, `SELL_CONDITION`, `TYPE_LABEL`)로 모듈을 만들고 `src/strategies/__init__.py`의 `STRATEGIES`에 등록하면 됩니다.

## 알아둬야 할 한계

1. **생존편향**: 종목 유니버스가 "오늘 기준 시가총액 상위"라, 과거 백테스트에 쓰면 그때는 작았다가 지금 커진 회사가 포함되고 상장폐지된 회사는 빠집니다. 기간이 길수록 수익률이 부풀려집니다.
2. **풋콜비율은 백테스트 불가**: 과거 옵션 데이터를 무료로 구할 수 없어 현재값 참고용입니다.
3. **하이일드 스프레드는 3년치만**: FRED 무료 CSV가 3년 정도만 제공합니다.
4. **COT는 미국 전용 + 3일 지연**: 매주 화요일 기준으로 집계해 금요일에 발표합니다. 한국은 KRX가 기관·외국인 데이터에 로그인을 요구해서 무료로는 받을 수 없습니다(`pykrx`로 확인 — 주가는 되지만 투자자별 데이터는 전부 차단).
5. **시장 타이밍**: 학계 연구는 일관되게 "타이밍 예측은 대부분 실패한다"고 말합니다. 상황판은 예측이 아니라 현재 상태 참고용입니다.

## 한글 경로 관련 주의

이 프로젝트는 경로에 한글이 포함되어 있습니다(`D:\1. 재건정보\...`). 그 때문에 두 가지 처리가 들어가 있습니다.

- `src/ssl_fix.py`: `curl_cffi`가 한글 경로의 인증서를 못 읽는 문제 → 인증서를 영문 임시 경로로 복사해서 사용
- `run_web.bat`: 배치파일에 한글을 넣으면 깨지므로 **ASCII만 사용**

## 텔레그램 알림 설정

알림은 두 종류이고 서로 무관합니다.

### 1. 종사종팔 매일 알림

**[TELEGRAM.md](TELEGRAM.md)** 에 단계별 안내가 있습니다.

매 평일 정해진 시각에 **어젯밤 마감 결과 + 오늘 넣을 주문**을 한 통으로 보냅니다.
손절일이 3영업일 안으로 다가온 물량도 미리 알려줍니다 — 목표 매도는 주문만 걸어두면 알아서 체결되지만, 손절은 날짜를 직접 세야 해서 제일 놓치기 쉽습니다.

설정하는 곳은 종사종팔 앱의 **`🔔 알림` 탭**입니다. 봇 토큰을 넣고 chat_id를 찾은 뒤 예약을 켜면, 윈도우 작업 스케줄러(`JongsaDailyNotify`)가 매 평일 실행합니다. 이 PC가 켜져 있어야 합니다.

PC를 꺼놔도 받고 싶다면 GitHub Actions(`.github/workflows/jongsa-daily.yml`)로 돌릴 수 있습니다. 저장소가 공개라 토큰·시드·시작일·앱 주소는 GitHub Secrets에서 읽습니다.

메시지를 만드는 코드는 `src/jongsa_notify.py` 하나뿐이라, 앱의 미리보기와 실제 발송 내용이 어긋나지 않습니다.

```powershell
# 보내지 않고 화면에만 미리보기
$env:JONGSA_DRY_RUN="1"; .venv\Scripts\python.exe scripts\jongsa_daily_notify.py
```

### 2. 종목 스캔 알림 (app.py 쪽)

웹앱의 "텔레그램 알림" 탭에서 전부 설정할 수 있습니다.

1. 텔레그램에서 **@BotFather** → `/newbot` → 봇 토큰 받기
2. 만든 봇에게 아무 메시지나 하나 보내기
3. 앱에서 봇 토큰 입력 → "내 chat_id 찾기" → 저장
4. 시간·시장·최소 일치개수 정하고 "예약 저장 및 켜기"

예약은 윈도우 작업 스케줄러(`QuantTraderDailyScan`)에 등록되며, 이 컴퓨터가 켜져 있고 로그인된 상태여야 실행됩니다.
