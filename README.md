# quant-trader

한국·미국 주식 대상 퀀트 전략 백테스트 + 스캔 도구. **자동 주문 기능은 없습니다** — 신호를 찾아주면 실제 매매는 본인이 증권사 앱에서 직접 합니다.

## 한국 / 미국 전환

앱 맨 위의 **🇰🇷 한국 주식 / 🇺🇸 미국 주식** 선택으로 전체 앱이 전환됩니다. 종목 검색·차트·백테스트·스캔·포트폴리오·텔레그램 예약이 모두 선택한 시장을 따라갑니다 (통화 표시도 원/달러로 바뀜).

| | 한국 | 미국 |
|---|---|---|
| 시장 | KOSPI, KOSDAQ | S&P500, NASDAQ, NYSE |
| 종목 지정 | 종목코드 (005930) | 티커 (AAPL) |
| 통화 | 원 | 달러 |
| 목록 순서 | 시가총액 큰 순 | NASDAQ·NYSE는 시가총액 순, **S&P500은 알파벳순** |

**S&P500 주의**: 알파벳순으로 오기 때문에 "상위 100개"를 고르면 규모 상위가 아니라 A로 시작하는 회사 위주가 됩니다. 앱에서 이 경우 경고를 띄웁니다. 규모 순으로 보려면 NASDAQ·NYSE를 쓰세요.

## 실행 방법

바탕화면의 **"퀀트트레이더 웹"** 바로가기를 더블클릭하면 브라우저(`http://localhost:8501`)가 자동으로 열립니다.

직접 실행하려면:

```powershell
.venv\Scripts\python.exe -m streamlit run app.py
```

## 처음 설치할 때

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 지원 전략 (9개)

크게 두 종류로 나뉩니다.

**오르는거 따라사기 (추세추종)**
| 이름 | 매수 | 매도 |
|---|---|---|
| `golden_cross` | 단기 이평선이 장기 이평선 위로 돌파 | 반대로 아래로 이탈 |
| `macd` | MACD선이 시그널선 위로 돌파 | 아래로 이탈 |
| `momentum` | 최근 20일 수익률이 플러스 | 마이너스로 전환 |
| `volatility_breakout` | 전일 변동폭의 k배만큼 시가 위로 상승 | 다음날 조건 미충족 시 |

**싸졌을때 줍기 (평균회귀)**
| 이름 | 매수 | 매도 |
|---|---|---|
| `rsi` | RSI 30 밑 (과매도) | RSI 70 위 (과매수) |
| `bollinger` | 볼린저밴드 하단 이탈 | 중심선 회복 |
| `disparity` | 이격도 95 밑 (평균보다 5%↓) | 이격도 102 회복 |
| `stochastic` | %K 20 밑 | %K 80 위 |

**가장 안전**
| 이름 | 매수 | 매도 |
|---|---|---|
| `high_breakout` | 최근 1년 최고가 갱신 | 최고가 아래로 하락 |

새 전략을 추가하려면 `src/strategies/`에 같은 인터페이스(`generate_signals`, `DEFAULT_PARAMS`, `BUY_CONDITION`, `SELL_CONDITION`, `TYPE_LABEL`)로 모듈을 만들고 `src/strategies/__init__.py`의 `STRATEGIES`에 등록하면 됩니다.

## 알아둬야 할 한계

1. **생존편향**: 종목 유니버스가 "오늘 기준 시가총액 상위"라, 과거 백테스트에 쓰면 그때는 작았다가 지금 커진 회사가 포함되고 상장폐지된 회사는 빠집니다. 기간이 길수록 수익률이 부풀려집니다.
2. **풋콜비율은 백테스트 불가**: 과거 옵션 데이터를 무료로 구할 수 없어 현재값 참고용입니다.
3. **하이일드 스프레드는 3년치만**: FRED 무료 CSV가 3년 정도만 제공합니다.
4. **시장 타이밍**: 학계 연구는 일관되게 "타이밍 예측은 대부분 실패한다"고 말합니다. 상황판은 예측이 아니라 현재 상태 참고용입니다.

## 한글 경로 관련 주의

이 프로젝트는 경로에 한글이 포함되어 있습니다(`D:\1. 재건정보\...`). 그 때문에 두 가지 처리가 들어가 있습니다.

- `src/ssl_fix.py`: `curl_cffi`가 한글 경로의 인증서를 못 읽는 문제 → 인증서를 영문 임시 경로로 복사해서 사용
- `run_web.bat`: 배치파일에 한글을 넣으면 깨지므로 **ASCII만 사용**

## 텔레그램 알림 설정

웹앱의 "텔레그램 알림" 탭에서 전부 설정할 수 있습니다.

1. 텔레그램에서 **@BotFather** → `/newbot` → 봇 토큰 받기
2. 만든 봇에게 아무 메시지나 하나 보내기
3. 앱에서 봇 토큰 입력 → "내 chat_id 찾기" → 저장
4. 시간·시장·최소 일치개수 정하고 "예약 저장 및 켜기"

예약은 윈도우 작업 스케줄러(`QuantTraderDailyScan`)에 등록되며, 이 컴퓨터가 켜져 있고 로그인된 상태여야 실행됩니다.
